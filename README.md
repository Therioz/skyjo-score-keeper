# Skyjo Marcador

Marcador de puntos para el juego de cartas Skyjo (2 a 8 jugadores). Funciona sin conexión y se puede añadir a la pantalla de inicio del iPhone o iPad.

- Añade los jugadores y apunta los puntos de cada ronda.
- La partida termina cuando alguien llega a 100: pierde quien tenga más puntos y gana quien tenga menos.
- Se puede corregir o borrar cualquier ronda desde el Historial.

Hecho con HTML, CSS y JavaScript sin dependencias. Para probarlo en local: `python3 -m http.server` y abre http://localhost:8000.
